# คู่มือผู้สร้างสื่อ

สมัครที่ `/creator` ยืนยันสิทธิ์ในผลงานและข้อตกลงผู้ขาย เมื่ออนุมัติจึงเพิ่มสื่อได้ ไฟล์ที่ส่งจะอยู่ temporary review จนกว่าจะผ่าน safety, copyright risk และ human review

ส่วนแบ่งเริ่มต้น 85%, verified 88%, trusted 90% ตามกฎที่มีผลขณะซื้อ ระบบ snapshot ทุก order รายได้พักตาม hold period ก่อน available และจ่ายแบบยอดสะสมเมื่อถึงขั้นต่ำ

Game URL เป็นข้อมูลป้องกันก่อนซื้อ แต่ผู้ใช้เห็น URL ปลายทางได้หลัง browser redirect ควรใช้ verification token `KRUPO-XXXX` บนแพลตฟอร์มที่รองรับและเตรียม backup ตามสิทธิ์ที่ KruPo เก็บได้
