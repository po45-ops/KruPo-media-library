# KruPo Design System

ภาพอ้างอิงที่อนุมัติกำหนดทิศทาง: พื้นขาว/ฟ้าอ่อน, header โปร่ง, navy/royal blue, mint สำหรับสถานะดี, lavender สำหรับหมวดหมู่, yellow เป็น accent เล็กน้อย, card มุมมนและ shadow บาง

Design tokens หลัก: Navy `#0B2F6B`, Blue `#0F5BD8`, Purple `#6554E8`, Soft `#EEF4FF`, Mint `#2FC58D`, Yellow `#F6B73C`, Text `#14243D`, Muted `#66758A`, Border `#E1E8F2`

ใช้ Noto Sans Thai หากเครื่องมี พร้อม system fallback; touch target อย่างน้อย 44px; focus ring ชัดเจน; mobile ใช้ compact header/bottom navigation และ filter drawer
